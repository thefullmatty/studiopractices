# Find the Field

A self-contained HTML/CSS/JS prototype for the Studio Process Site.

## Files

- `index.html` — main page
- `styles.css` — layout and visual system
- `script.js` — prompt banks, cascading form behaviour, draggable physics map, text download
- `01-base-shape.svg` — base panel artwork
- `02-interactives.svg` — reference/control artwork, kept in folder but HTML controls are used instead

## How to use

Open `index.html` in a browser. Fill the fields, then press the circular `+` button to add an entry to the map.

The tool stores entries in `localStorage` so refreshes should preserve the current map. Use **Clear map** to reset it.

Add `?demo` to the URL if you want the demo entries to appear automatically.
